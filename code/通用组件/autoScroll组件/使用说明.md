# AutoScroll 滚动组件

一个基于 **Vue3** 的自动垂直滚动组件。支持无缝滚动、鼠标悬停暂停、外部控制滚动速度和容器高度。

---

## ✨ 特性
- 支持 slot 传入任意内容  
- 当内容不足以滚动时自动静止  
- 可控是否滚动、滚动速度  
- 鼠标悬停暂停，移开恢复  
- 外部可设置容器高度  

---

## 📦 使用方式

```vue
<script setup>
import AutoScroll from './components/AutoScroll.vue'
</script>

<template>
  <AutoScroll :height="'300px'" :speed="1.5" :auto="true">
    <ul>
      <li v-for="i in 20" :key="i">测试数据 {{ i }}</li>
    </ul>
  </AutoScroll>
</template>
